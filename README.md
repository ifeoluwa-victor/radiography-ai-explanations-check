# Radiography AI Explanations Check

A student project where I take AI-style statements about radiography and ultrasound, check them against reputable public sources, and write a corrected version.

> **Educational only.** This is a learning project by a Radiography student. It gives no patient-specific medical advice and is not a clinical guide.
> **AI disclosure:** I used Claude (Anthropic) to help draft the starting files, including the example AI-style statements. I check each one against sources myself and record what I find.

## What this project shows
- Splitting an AI answer into single claims
- Checking each claim against a reliable source
- Spotting hallucinations, missing context, overconfident wording and unsupported conclusions
- Writing a safer, corrected explanation
- Why supervision and professional judgement still matter in imaging

## My checking method
1. Split the answer into single claims.
2. Check the riskiest claims first (safety, dose, diagnosis).
3. Find a source from a professional body, health service or textbook.
4. Compare the wording of the source with the claim.
5. Label the problem: hallucination, missing context, overconfident, or unsupported conclusion.
6. Write a corrected version in simple language.
7. Record the source and the date I accessed it.

If I cannot find a source, I write "not verified". I do not invent citations.
